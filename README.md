# Awais Portfolio - HTML Version

This is a pure HTML, CSS, and JavaScript version of the Muhammad Awais portfolio website, converted from the original React/TypeScript implementation.

## 📁 Files Included

- `index.html` - Main HTML structure
- `styles.css` - All styling and animations
- `script.js` - Interactive functionality and animations
- `README.md` - This file

## 🚀 How to Use

1. **Open the website**: Simply double-click on `index.html` or open it in your web browser
2. **No build process required**: This is a static website that runs directly in the browser
3. **No dependencies**: No npm, Node.js, or any other tools needed

## ✨ Features

- **Preloader Animation**: 2.5-second loading animation on page load
- **Smooth Scrolling**: Navigation links smoothly scroll to sections
- **Scroll Animations**: Elements fade in as you scroll down
- **Responsive Design**: Works on desktop, tablet, and mobile devices
- **Interactive Elements**: Hover effects, transitions, and animations
- **Contact Form**: Functional form with validation (ready for backend integration)

## 🎨 Sections

1. **Hero Section**: Introduction with name, title, and call-to-action buttons
2. **About Section**: Professional background and statistics
3. **Skills Section**: Technical skills organized by category (Frontend, Backend, Tools, Testing)
4. **Projects Section**: Portfolio of selected works with images and descriptions
5. **Experience Section**: Career timeline with roles and achievements
6. **Contact Section**: Contact form and contact information
7. **Footer**: Social media links and copyright

## 🛠️ Customization

### Changing Colors
Edit the CSS variables in `styles.css`:
```css
:root {
    --color-primary: #81e9ff;
    --color-surface: #0c0e11;
    /* ... other colors */
}
```

### Updating Content
Edit the HTML content directly in `index.html`:
- Change text, titles, descriptions
- Update project images and information
- Modify contact details

### Adding Functionality
Edit `script.js` to add more interactive features:
- Connect the contact form to a backend service
- Add more animations
- Integrate analytics
